Утилита для анализа погруженности сотрудников в функционал.

    - Количество кейсов, созданных каждым из сотрудников
    - Общее количество кейсов в функционале

<h1> Конфигурирование </h1>

В данный момент есть возможность конфигурирования списка сотрудников, результаты анализа погружения которых будут отображены.
Данный список находится в файле `/src/main/resources/membersList.yaml`. Будут отображены результаты анализа погружения только незакомментированных сотрудников, перечисленных в ключе `relevantMembers` указанного yaml конфига.
Независимо от значения ключа `relevantMembers`, анализ погружения проводится для всех сотрудников, кто проходил или создавал кейсы в проекте. Указанный конфиг влияет только на отображение данных.

Пример конфига:

```YAML
relevantMembers:
#Список участников проекта, для которых будет проведен анализ погружения
  - asuzdaltsev
  - vkomisarova
  - ekpetrova
  - ishimkene
  - mzviagina
  #- sstepichev
```
